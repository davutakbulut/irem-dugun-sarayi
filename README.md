# 🏰 İrem Düğün Sarayı & Organizasyon Platformu

Full-stack düğün salonu, organizasyon ve rezervasyon yönetim platformu.

## 🚀 Özellikler
- **Müşteri Portalı:** Salon inceleme, tarih müsaitlik kontrolü, organizasyon ve paket inceleme.
- **Yönetim Paneli:** Rezervasyon yönetimi, takvim, finans/gider takibi, müşteri ilişkileri, medya galeri yönetimi.
- **Medya Yükleme & Klasör Senkronizasyonu:** Rezervasyon bazlı medya galerisi, otomatik fiziksel sunucu senkronizasyonu ve mükerrer dosya kontrolü.
- **Backend API:** Node.js Express REST API, JSON DB & MariaDB/MySQL desteği.

## 🛠️ Kurulum ve Çalıştırma

### Bağımlılıkları Yükleme
```bash
npm install
```

### Geliştirme Sunucusunu Başlatma
```bash
npm start
```
Sunucu varsayılan olarak `http://localhost:5001` portunda yayına girer.
